# The Cut Studio

Application web/mobile de **The Cut Studio**, salle de jeux vidéo située à Kasapa, Lubumbashi (RDC).

L'application prolonge l'activité de la salle en ligne :

- consultation du catalogue (consoles PS5, jeux PS4) avec prix en francs congolais ;
- réservation de sessions de jeu ;
- tournois en ligne avec inscription et paiement ;
- boutique en ligne (jeux, consoles, accessoires) ;
- paiement mobile ;
- tableau de bord pour le gérant (clients, chiffre d'affaires, dépenses, bénéfice).

> Projet universitaire – Université Protestante de Lubumbashi (UPL) – Faculté des Sciences informatiques – Année 2025-2026.
